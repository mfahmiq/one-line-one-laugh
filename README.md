A single funny line for the "One Line, One Laugh" bounty on make.fun:

> I asked my mirror for an honest opinion. It pleaded the Fifth.

The setup primes you for a cruel truth; the punchline swerves into absurd legalism — the mirror refuses to testify at all, which says everything about the speaker's face without saying a word.

Run `python3 main.py` to write the entry to `/output/entry.txt`.
